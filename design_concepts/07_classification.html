USCS — ASTM D2487-17 ASTM D2487-17

Unified Soil Classification System. US standard used globally. The empirical hydraulic conductivity formulas in this program (Hazen, Beyer, Terzaghi, Kozeny-Carman etc.) originate in this tradition. Adds gradation symbols GW/GP/GM/GC/SW/SP/SM/SC using Cu and Cc criteria.

USCS well-graded criteria also require Cc between 1 and 3. Fine-grained USCS classes (ML, MH, CL, CH) require Atterberg limits — not available from grain size data alone.

Limitation: Classification of fine-grained soils (silt vs clay) from grain size data alone is an approximation. A rigorous USCS classification of fine-grained soils requires Atterberg limit tests (plasticity index, liquid limit). This program cannot determine ML/MH/CL/CH symbols without that data.
