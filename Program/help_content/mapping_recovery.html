Mapper Workflow

Mapping & Recovery

Use the mapper when the correct data exists in the file but the loader needs you to confirm where it is.

When The Mapper Appears

  • Excel workbooks are imported through manual mapping by default.
  • CSV or workbook layouts with ambiguous headers may need manual confirmation.
  • Error tabs can reopen the mapper if a file was not loaded correctly the first time.

Choose The Right Path

Choice Use it when
Calculated Data Your file already contains particle size and cumulative percent passing.
Raw Sieve Weighings Your file contains sieve size, empty sieve weight, and sieve plus sample weight.
Column Mapping The data is arranged in consistent columns and the same mapping can be reused across checked sheets.
Cell Range Selection The sheet is irregular and you need to mark the exact size cells and percent cells directly in the preview.
Range mode limit

Cell Range Selection works one sheet at a time. If several sheets share the same irregular layout, map one sheet first and then use Apply Pattern to Batch.

Basic Column Mapping Steps

  1. Pick the correct sheet in the preview area.
  2. Set the header row if the detected headers are wrong.
  3. Choose the size and percent columns, or the raw sieve weight columns.
  4. Check the sample name, temperature, and porosity fields.
  5. Accept the dialog to create dataset tabs from the selected sheet or sheets.

Error Recovery Workflow

  1. Open the error tab for the failed file.
  2. Review the preview and the raw loader message.
  3. Use Open Mapper to correct the sheet or column choices.
  4. Accept the mapper to replace the error tab with one or more datasets.
What to verify before accepting
  • Particle sizes look like millimeter values.
  • The percent column is cumulative passing, not retained.
  • The preview rows stay aligned after the header row.
  • Checked sheets really share the same layout.
