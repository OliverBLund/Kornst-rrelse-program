Shepherd Method

The Shepherd method (1989) is a modern empirical formula based on statistical analysis of permeability test data. It uses both D₁₀ and D₅₀, making it applicable to a wider range of grain size distributions than methods using only D₁₀.

Formula

K = a × D₁₀^b × D₅₀^c

Where:

  • K = Hydraulic conductivity (cm/s)
  • a = 24.5 (coefficient)
  • b = 0.783 (exponent for D₁₀)
  • c = 1.177 (exponent for D₅₀)
  • D₁₀, D₅₀ = Grain sizes in cm
Important: The Shepherd method does NOT include temperature correction. It provides K at the temperature of the original correlation (typically 20°C).

Required Parameters

  • D₁₀ (10% passing)
  • D₅₀ (50% passing - median grain size)

Applicability

Parameter Range
D₁₀ 0.01 - 1.0 mm
D₅₀ 0.05 - 2.0 mm
Soil type Sands and gravels

Example Calculation

Given:
D₁₀ = 0.12 mm = 0.012 cm
D₅₀ = 0.35 mm = 0.035 cm

Calculate:
K = 24.5 × (0.012)^0.783 × (0.035)^1.177
K = 24.5 × 0.0178 × 0.0298
K = 1.30×10⁻² cm/s
K = 1.30×10⁻⁴ m/s
K = 11.2 m/d

Statistical Basis

Shepherd developed this formula through regression analysis of 67 permeability measurements from unconsolidated sands and gravels. The correlation coefficient was R² = 0.94, indicating excellent predictive capability.

Advantages

  • Uses both D₁₀ and D₅₀ (more information than D₁₀-only methods)
  • Based on actual permeability measurements
  • Good accuracy for sands and gravels
  • Simple power-law formula
  • Well-documented validation

Limitations

  • No temperature correction (assumes 20°C)
  • Requires reliable D₅₀ determination
  • Limited to unconsolidated granular materials
  • Not suitable for fine-grained soils

Comparison with Other Methods

Method Parameters Used Temperature Correction
Hazen D₁₀ only Yes
Shepherd D₁₀ + D₅₀ No
Beyer D₁₀ + Cu Yes

When to Use

Shepherd is recommended when:

  • Working with sands and gravels
  • D₅₀ is reliably determined
  • Grain size distribution is complete
  • Temperature is close to standard conditions (15-25°C)

Reference

Shepherd, R.G. (1989). "Correlations of permeability and grain size." Ground Water, 27(5), 633-638.
