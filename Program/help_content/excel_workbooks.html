Excel Import

Excel Workbooks

Excel import is conservative by design. The application prefers a short manual check over guessing the wrong sheet or the wrong columns.

What Happens On Import

  1. If the workbook has one sheet, import continues directly.
  2. If it has multiple sheets, the Sheet Selector opens first.
  3. After sheet selection, the Column Mapper opens so you can confirm the data layout.
  4. Each selected sheet becomes its own dataset in the workspace.

Multi-Sheet Behavior

Situation Behavior
One workbook, many sheets You can check one or more sheets to import before mapping.
Several workbooks with the same sheet structure The app can apply one sheet selection across the full batch.
Calculated column mapping The same checked-sheet mapping can be reused across multiple sheets in the workbook.
Cell range selection This mode works one sheet at a time because the selected cells are sheet-specific.
Preview rules

Inside the mapper, the selected sheet controls the preview table. If you change sheets, re-check that the header row and column choices still match the visible data.

Irregular Lab Sheets

Use Cell Range Selection when the size and percent values are not stored in clean columns. For repeated layouts, map one representative sheet first and then use Apply Pattern to Batch.

Raw Sieve Workbooks

When the workbook contains empty-sieve and sieve-plus-sample weights, switch the mapper to Raw Sieve Weighings. That path uses column mapping only.
