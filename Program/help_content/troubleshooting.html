🔧 Troubleshooting

Solutions to common problems when using the Grain Size Analysis application.

File Loading Issues

File Shows "⚠️ Needs Review"

Problem: Application cannot automatically detect column format

Solutions:

  1. Right-click the file in the sample table
  2. Select "🗺️ Map Columns..."
  3. Manually specify which columns contain:
    • Particle Size (mm)
    • Percent Passing (%)
  4. Click "OK" to load with manual mapping

File Shows "❌ Failed"

Possible Causes:

  • Data validation errors (values out of range)
  • Data represents "percent retained" instead of "percent passing"
  • Non-numeric values in data columns
  • Insufficient data points (< 3 sieve sizes)

Solutions:

  1. Right-click and select "🔧 Fix/Remap..."
  2. Review the error message in the error tab
  3. Check your data file:
    • Ensure particle sizes are in millimeters (mm)
    • Ensure percent passing (not retained)
    • Remove any text or blank cells in data rows
    • Include at least 3 sieve sizes
  4. If data is "percent retained", convert using: % passing = 100 - % retained

Grain Size Curve Looks Inverted

Problem: Curve goes up instead of down

Cause: Data represents "percent retained" rather than "percent passing"

Solution:

  • Convert your data: % passing = 100 - % retained
  • Save the corrected file and reload

File Won't Load at All

Checklist:

  • ✓ File is CSV (.csv) or Excel (.xlsx, .xls)
  • ✓ File contains numeric data (not formulas or text)
  • ✓ File encoding is UTF-8 or standard ASCII
  • ✓ File is not password-protected
  • ✓ No special characters in filename or path

Calculation Issues

All Methods Show "Error" Status

Possible Causes:

  • Missing characteristic grain sizes (D₁₀, D₅₀, D₆₀)
  • Grain size distribution too fine or too coarse
  • Invalid porosity value

Solutions:

  1. Check "Stats" tab to see if D₁₀, D₅₀, D₆₀ are calculated
  2. If missing, your sample may need additional sieve sizes:
    • For D₁₀: Need sieves showing 5-15% passing
    • For D₅₀: Need sieves showing 45-55% passing
    • For D₆₀: Need sieves showing 55-65% passing
  3. Verify porosity is in valid range (0.1-0.8)

Wide Variation in K Values

Problem: Methods disagree significantly (>10x difference)

Explanations:

  • Normal - Different methods have different applicability
  • Gap-graded soil - Some methods not suitable
  • Fine-grained sample - Empirical methods less accurate

Solutions:

  1. Focus on methods showing "OK" status
  2. Use median K value rather than mean
  3. Report result as a range
  4. Consider laboratory permeability test for validation

Porosity Value Seems Wrong

Problem: Calculated porosity outside expected range

Solutions:

  1. Check "Stats" tab to see porosity calculation details
  2. Try switching porosity mode:
    • Expand "⚙️ Analysis Parameters"
    • Toggle between "Simple Formula" and "Urumovic Polynomial"
  3. If you have measured porosity, manually override:
    • Go to "Stats" tab
    • Find "Porosity Settings"
    • Enter measured value
    • Click "Update"

Display Issues

Can't See All Columns in Table

Solution:

  • Widen the window
  • Scroll horizontally in the table
  • Adjust column widths by dragging headers

Plot Not Showing

Solutions:

  1. Ensure data is loaded (check if tab exists)
  2. Click the "Plot" sub-tab in the dataset
  3. Try resizing the window
  4. Restart the application

Text Too Small/Large

Solutions:

  • Adjust Windows display scaling (Settings → Display)
  • Resize application window

Export Problems

Export Button Disabled

Cause: No results calculated yet

Solution:

  1. Click "🔬 Calculate All Samples" in toolbar
  2. Wait for calculations to complete
  3. Export buttons will become enabled

Export File Won't Open

For CSV exports:

  • Ensure you have Excel or compatible spreadsheet software
  • Try opening in text editor first to verify file integrity

For plot exports:

  • PNG: Should open in any image viewer
  • PDF: Requires PDF reader (Adobe Acrobat, browser, etc.)
  • SVG: Requires vector graphics software or modern browser

Performance Issues

Application Runs Slowly

Possible Causes & Solutions:

  • Many samples loaded - Close unused dataset tabs
  • Large files - Consider downsampling to key sieve sizes
  • Old computer - Close other applications

Calculations Take Too Long

Normal behavior:

  • 14+ methods × number of samples
  • Should complete in < 5 seconds for typical data

If longer:

  • Check if many samples are loaded
  • Restart application if stuck

Error Messages

"Could not parse file"

Meaning: File format not recognized

Solution: Use Column Mapper to manually specify format

"No valid data found"

Meaning: No numeric grain size data detected

Solution: Verify file contains proper numeric columns

"Column mapping needed"

Meaning: Automatic detection failed

Solution: Right-click file → "Map Columns..."

"D10 required"

Meaning: Cannot interpolate D₁₀ from grain size distribution

Solution: Add sieve data showing 5-15% passing

Data Quality Warnings

"Non-monotonic grain size data detected"

Meaning: Percent passing doesn't consistently decrease with grain size

Causes:

  • Data entry errors
  • Laboratory measurement variability
  • Using "percent retained" instead of "percent passing"

Actions:

  1. Review raw data for errors
  2. If many violations (>50%), likely using percent retained
  3. Minor violations (<3 points) are usually acceptable

"Unusual grain sizes detected"

Meaning: Grain sizes outside typical 0.001-1000 mm range

Solution:

  • Verify units are millimeters (not meters or micrometers)
  • Check for data entry errors

Known Limitations

  • Empirical methods only - Not a substitute for laboratory testing
  • Granular soils - Methods designed for sands and gravels, less accurate for clays
  • Clean soils - Assumes minimal fines content
  • Temperature range - 0-50°C for reliable corrections
📌 Remember: Empirical K estimates are approximations. For critical projects, validate with laboratory permeability tests (constant head, falling head, etc.).
