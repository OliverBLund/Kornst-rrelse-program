Application Information

Grain Size Analysis - Hydraulic Conductivity Calculator

Version 2.0

A professional PyQt6 desktop application for estimating hydraulic conductivity from grain size distribution data using multiple empirical methods.

Features

  • 14+ empirical calculation methods
  • Automatic file format detection
  • Batch processing of multiple samples
  • Interactive grain size distribution plots
  • Temperature and porosity corrections
  • Statistical analysis and comparison
  • Professional report generation
  • Export to CSV, Excel, PNG, PDF, SVG

Calculation Methods

The application implements methods from established geotechnical and hydrogeological literature:

Classic Methods (Pre-1950)

  • Hazen (1892, 1911) - Simple D₁₀² formula for uniform sands
  • Slichter (1899) - Porosity-dependent formula
  • Terzaghi (1925) - Distinguished smooth vs. angular particles

Mid-Century Developments (1950-1980)

  • Kozeny-Carman - Theoretical capillary model
  • Beyer (1964) - Uniformity coefficient dependent
  • Sauerbrei (1932) - German standard method
  • Zunker (1932) - Special diameter calculation
  • Zamarin (1928) - Geometric mean approach

Modern Methods (1980-Present)

  • Shepherd (1989) - Empirical formula for sands
  • USBR (1990s) - US Bureau of Reclamation
  • Barr (2001) - Cubic porosity function
  • Alyamani & Sen (1993) - Saudi Arabian aquifers
  • Chapuis (2004) - Void ratio dependent
  • Kruger - Special harmonic mean

Technical Details

Programming

  • Language: Python 3.8+
  • GUI Framework: PyQt6
  • Plotting: Matplotlib
  • Numerical: NumPy, SciPy
  • Data Handling: Pandas

Calculation Engine

  • Units: Input in mm, calculations in cm, output in m/s
  • Interpolation: Linear interpolation for percentiles (D₁₀, D₅₀, etc.)
  • Precision: Double-precision floating point
  • Special diameters: Harmonic mean, geometric mean, Zamarin, Zunker, Kruger
