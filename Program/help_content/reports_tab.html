Tab Guide

Reports Tab

The Reports tab turns one or more datasets into a formatted document. Pick a report type, optionally adjust the content, choose an output format, and generate.

Report Types

Report type Samples What it includes
Individual Sample Exactly one That sample's grain-size curve, K-value bar chart, method applicability heatmap, and tables.
Cross-Sample Comparison Two or more Side-by-side plots (grain-size overlay, K-value bars, K box plots) plus overall/group aggregate summaries.
Full Project Summary All loaded The comparison plots and tables for every dataset, with appendices.
K-Value Focus One or more Hydraulic-conductivity tables, group aggregates, K box plots, and the lognormal K-distribution plot.
Types are templates, not locks

Choosing a report type pre-sets the section, plot, and sample-selection toggles. Everything stays editable, so you can start from a template and tick exactly the sections, tables, and plots you want.

Steps

  1. Pick a report type.
  2. Select the samples (the type sets the rule: one, two-or-more, or all).
  3. Adjust Main Sections, Plots to Include, and Appendices.
  4. Choose the output format: HTML, PDF, or Word (.docx).
  5. Generate, then preview, print, or save.

Cover Page and Branding

The optional cover page is designed to work as either a branded cover or a clean text-only title page.

  • Project information: the project name, project number, location, client, prepared-by name, and your entered report date are arranged in a compact cover summary.
  • Optional logo: add a PNG, JPG, or SVG logo under Branding. Wide and tall images are fitted inside a fixed logo area so they cannot distort the page.
  • No image: choose Remove beside the logo control for a balanced text-only cover. The program does not create a placeholder badge.
  • Word output: the title, subtitle, organization details, and project summary remain editable Word content. Report content starts on the next page, while the cover stays free of report headers and footers.
Use Word when the report needs a final editorial pass

Word (.docx) is the best choice when recipients need to revise wording, move sections, add commentary, or apply a client template after export. PDF is the fixed-layout delivery format.

Plots To Include

  • Per sample: each selected sample's own grain-size curve and K-value bar. Opt-in for multi-sample reports, so a large project does not render dozens of figures unless you ask.
  • Across samples: the comparison plots — grain-size comparison, K-value comparison bars, K distribution box plots, the lognormal K-distribution, and the method reliability matrix. These need two or more samples.
Report content stays traceable to the application

Reports include only the data tables produced by the program and the plots selected in the Reports tab. The exporter does not invent substitute or fallback charts.

Plot Style

The Plot Style control sets how report plots look, with one rule: the preset sizes the text, the palette colours the data.

  • Preset (Professional, Presentation, …) — typography only. Use Presentation for large text.
  • Palette (Categorical, Viridis, Grayscale, …) — the colours of the data series. Categorical keeps the standard colours; a colour map recolours every plot; Grayscale is for black-and-white printing.
  • Customize… fine-tunes legend and font sizes on top of the preset.

The Reports and Export tabs share these settings, so you theme your output once.

Large reports run in the background

Generating a big report runs in a background task with a progress dialog you can cancel, so the app stays responsive. The preview and the exported PDF show the whole report even when it embeds many figures.
