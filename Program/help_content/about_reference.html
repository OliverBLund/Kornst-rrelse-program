About & References

Grain Size Analysis is a DTU-oriented desktop tool for grain-size interpretation, hydraulic conductivity estimation, comparison, reporting, and export.

What This Help Set Covers

  • Getting a new user from import to a valid workspace.
  • Understanding the current Excel, mapping, comparison, and export flow.
  • Keeping operational guidance aligned with the present UI.

Primary Reference Direction

The application’s method coverage and terminology are aligned with empirical hydraulic conductivity work based on grain-size distributions. Use the in-app method status and detailed references in each method page when preparing a final interpretation.

Project & Provenance

  • Developed by Oliver Lund at DTU Sustain.
  • Made in collaboration with Poul Løgstrup Bjerg at DTU Sustain.
  • Is a further development of HydrogeoSieveXL, the original tool developed by J. F. Devlin.

Original Software & Article

HydrogeoSieveXL software page

Devlin, J. F. (2015). HydrogeoSieveXL: an Excel-based tool to estimate hydraulic conductivity from grain-size analysis. Hydrogeology Journal. DOI 10.1007/s10040-015-1255-0.

Version Context

This help system is written for the current interface with the top-level tabs Home, Individual Samples, Comparison, Reports, and Export.

Practical scope

The help pages focus on how to operate the software correctly. They do not replace method validation, laboratory judgement, or project-specific reporting requirements.
