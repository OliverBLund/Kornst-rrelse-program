Tab Guide

Comparison Tab

The Comparison tab works across datasets. It needs at least two datasets, and uses the subset selected in the sidebar (if nothing is selected, it uses all loaded datasets). Inside it are three subtabs — Plot, Details, and Statistics.

Plot Subtab

Choose a plot type, then how to lay it out and break it down.

Plot type Shows
DistributionThe grain-size curves of the datasets together.
K-ValuesHydraulic-conductivity bars across datasets (or groups).
K DistributionThe pooled K values as a lognormal histogram (or, optionally, an empirical CDF).
CombinedDistribution and K-values together, one panel per dataset or group.
HistogramThe grain-size histogram per dataset or group.
  • Layout: Overlay draws everything on one set of axes; Grid gives each dataset or group its own panel (2×2 up to 4×3).
  • Breakdown (shown when named groups exist): Per dataset draws each dataset; Per group aggregates each named group into one series.
  • The K Distribution sidebar adds its own controls — chart (lognormal histogram or empirical CDF), histogram axis (ln K or K), bins, frequency vs. density, drop-empty-bins, and N labels.
  • The plot sidebar also controls which datasets and groups are visible and the per-tab plot styling.
  • Export Figure in the plot toolbar saves the active plot as PNG, SVG, or PDF. The Table drawer exports the exact plotted data as CSV or Excel.
Groups

Group names come from Scope & Groups in the main sidebar. Groups feed the per-group breakdown, the aggregate statistics, and the group-aware report and export plots.

Details Subtab

  • A side-by-side table of the selected datasets — percentiles, gradation, classification, and K values for direct comparison.
  • Use Export Table… to save the currently visible rows and columns as CSV or Excel.

Statistics Subtab

  • Aggregate statistics across the selected datasets, including overall and per-group summaries.
  • Group-aware box plots and a method reliability/applicability view summarise how methods behave across the set.
  • Use Export Table… to save the active statistics table as CSV or Excel.
If comparison looks incomplete

Check the sidebar selection first — comparison uses the selected subset. Clear the selection to fall back to all loaded datasets, or press Analysis > Update Comparison after changing global settings.
