Tab Guide

Individual Samples Tab

The Individual Samples tab works one dataset at a time. Each loaded dataset has its own tab, and inside it three subtabs — Plot, Results, and Statistics. Use the sidebar to switch which dataset is active.

Plot Subtab

Shows graphics for the active dataset. Pick what to draw with the buttons and the More Plots… menu.

Plot Shows
Dist. Curve The grain-size distribution (percent passing vs. grain diameter). The default view.
K-Values A bar chart of the hydraulic-conductivity estimate from each method.
Combined (More Plots…) The distribution and the K-values side by side.
Histogram (More Plots…) The grain-size histogram (weight retained per size class).
  • The D-lines toggle shows the D10/D50/D60 reference lines on the curve.
  • The Controls button opens a sidebar for axes, units, labels, reference lines, and K-value display options.
  • A per-tab style preset, Sample color (click the swatch to recolour this sample's curve), and Legend & Typography control how this on-screen plot looks. Reports Plot Style and Export Plot Appearance share a separate saved style for generated output.

Results Subtab

A table of every method's hydraulic-conductivity estimate, with a detail panel for the selected row.

Column Meaning
MethodThe empirical K-method name.
CategoryThe method family.
K (cm/s), K (m/s), K (m/d)The estimate in each unit.
StatusOK, or a warning/error when the sample is outside the method's recommended range.
  • Select a row to see the method's formula, the grain size it used, and why it was flagged.
  • Which methods appear is set globally by Analysis > Choose K Methods…

Statistics Subtab

K summary scope: The Hydraulic Conductivity Summary uses positive OK results from all active methods. Warnings and errors are excluded. Change the active set under Analysis > Choose K Methods.

A read-only per-sample summary of everything computed that the Results table does not already list, grouped into sections:

  • Summary strip — sample name and point count, soil class, D50, uniformity coefficient (Cu), and the geometric-mean K with the number of included methods.
  • Key Grain Distribution — the characteristic diameters (D10/D50/D60/D90), a full percentile grid (D5–D95 by interpolation), and which K methods use each diameter.
  • Classification & Fractions — the detailed ISO 14688 sub-class breakdown (fine/medium/coarse sand, etc.) for the active scheme, the standard label, a plain-language descriptor, and Cu / Cc / sorting / span.
  • Hydraulic Conductivity Summary — geometric and arithmetic mean, median, range, and the ln(K) spread of the included methods.
  • Interpretation, Data Support & Calculation Context — a short factual read of the result, gradation-curve coverage checks, and the temperature, porosity, and permeability class.
  • Calculation Internals (collapsible) — the intermediate values behind the K methods: water physical constants, effective diameters, φ-unit Folk-Ward sorting, and porosity functions.
Global settings drive these views

Temperature, porosity mode, the classification scheme, and the active K-method set come from the Analysis menu, so every dataset tab stays consistent. See Analysis Parameters.
