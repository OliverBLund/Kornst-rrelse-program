Tab Guide

Individual Samples Tab

The Individual Samples tab works one dataset at a time. Each loaded dataset has its own tab, and inside it three subtabs — Plot, Results, and Statistics. Use the sidebar to switch which dataset is active.

Plot Subtab

Shows graphics for the active dataset. Pick what to draw with the buttons and the More Plots… menu.

Plot Shows
Dist. Curve The grain-size distribution (percent passing vs. grain diameter). The default view.
K-Values A bar chart of the hydraulic-conductivity estimate from each method.
Combined (More Plots…) The distribution and the K-values side by side.
Histogram (More Plots…) The grain-size histogram (weight retained per size class).
  • The D-lines toggle shows the D10/D50/D60 reference lines on the curve.
  • The Controls button opens a sidebar for axes, units, labels, reference lines, and K-value display options.
  • A per-tab style preset, Curve Color, and Legend & Typography control how this on-screen plot looks. (The single global Plot Style in the Reports and Export tabs controls report and export plots instead.)

Results Subtab

A table of every method's hydraulic-conductivity estimate, with a detail panel for the selected row.

Column Meaning
MethodThe empirical K-method name.
CategoryThe method family.
K (cm/s), K (m/s), K (m/d)The estimate in each unit.
StatusOK, or a warning/error when the sample is outside the method's recommended range.
  • Select a row to see the method's formula, the grain size it used, and why it was flagged.
  • Which methods appear is set globally by Analysis > Choose K Methods…

Statistics Subtab

Per-sample numbers grouped into sections:

  • Grain Size Percentiles and Percentile Usage by Methods — D-values and which methods rely on each.
  • Gradation Parameters — uniformity (Cu) and curvature (Cc).
  • Classification Criteria — the soil classification result for the active scheme.
  • Special Method Diameters — diameters specific methods require.
  • Environmental Parameters — temperature and porosity used for this dataset.
  • K-statistics — summary statistics across the included methods.
Global settings drive these views

Temperature, porosity mode, the classification scheme, and the active K-method set come from the Analysis menu and the sidebar, so every dataset tab stays consistent. See Analysis Parameters.
