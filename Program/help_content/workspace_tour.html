Workspace Tour

This page explains where to work in the app and what each selection changes.

Prefer an interactive tour?

Open Help > Startup Guide to have the app spotlight each area in turn, or Help > Guide Individual Samples for a focused walkthrough of one dataset's subtabs. This page is the written version.

Window Layout

The top of the window has two horizontal strips, one above the other:

  • Menu bar (top strip) — the classic menus File, Analysis, View, and Help, plus the window title and the minimise / maximise / close buttons. Data loading, exports, K methods, the analysis settings, and the guided tours all live here.
  • Toolbar (just below the menus) — the four workspace tabs on the left (Individual Samples, Comparison, Reports, Export) and the Log and Help buttons on the right. The same four tabs are also in the View menu as Ctrl+1–Ctrl+4.

Top-Level Tabs

Tab Use it for
Individual Samples Open dataset tabs, inspect one sample at a time, and recover files that need remapping.
Comparison Compare a selected subset of loaded datasets in shared Plot, Details, and Statistics views.
Reports Build a formatted HTML, PDF, or Word document from a report-type template (Individual, Cross-Sample Comparison, Full Project Summary, or K-Value Focus) that you can customize before generating.
Export Build the final export set for all datasets, the current dataset, or the selected dataset subset using the formats and content chosen inside the export workspace.

Dataset Tabs And Subtabs

  • Each loaded dataset gets its own tab inside Individual Samples.
  • Files that failed to load can appear as error tabs until they are fixed.
  • Inside a dataset tab you work across Plot, Results, and Statistics.

Sidebar Behavior

  • The sidebar is hidden while the welcome screen is shown.
  • Once datasets load, the sidebar shows a drag-and-drop drop zone, file cards, status filter pills, and the Scope & Groups control. Global analysis settings are in the Analysis menu, not the sidebar.
  • The drop zone at the top of the sidebar accepts dragged CSV, Excel, or TXT files; click it to choose processed or raw sieve import.
  • Clicking a card opens the matching dataset tab.
  • Expanding a card reveals quick actions such as inspect, log, properties, and remove.
  • The selection toggle on each card marks that dataset as part of the current comparison subset.

What Selection Changes

Selection source Affects Does not affect
Sidebar-selected cards The active dataset subset used by the Comparison tab. The All or Current export scopes.
No sidebar cards selected Comparison falls back to all loaded datasets. Nothing is excluded from export automatically.
Export scope selector Whether export runs for All datasets, the Current dataset, or the Selected dataset set. The comparison subset in the sidebar.
Practical rule

If comparison results look incomplete, check the sidebar selection first. If export results look incomplete, check the Export tab scope selector and whether Selected is meant to follow the sidebar/comparison dataset set.
