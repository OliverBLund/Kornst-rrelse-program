Workspace Tour

This page explains where to work in the app and what each selection changes.

Top-Level Tabs

Tab Use it for
Individual Samples Open dataset tabs, inspect one sample at a time, and recover files that need remapping.
Comparison Compare a selected subset of loaded datasets in shared Plot, Details, and Statistics views.
Reports Build report outputs using the report type and sample-selection rules shown inside that tab.
Export Export all datasets or the current dataset in the formats selected in the export panel.

Dataset Tabs And Subtabs

  • Each loaded dataset gets its own tab inside Individual Samples.
  • Files that failed to load can appear as error tabs until they are fixed.
  • Inside a dataset tab you work across Plot, Results, and Statistics.

Sidebar Behavior

  • The sidebar is hidden while the welcome screen is shown.
  • Once datasets load, the sidebar shows file cards, status filters, and global analysis controls.
  • Clicking a card opens the matching dataset tab.
  • Expanding a card reveals quick actions such as inspect, log, properties, and remove.
  • The selection toggle on each card marks that dataset as part of the current comparison subset.

What Selection Changes

Selection source Affects Does not affect
Sidebar-selected cards The active dataset subset used by the Comparison tab. The main Export tab scope.
No sidebar cards selected Comparison falls back to all loaded datasets. Nothing is excluded from export automatically.
Export scope selector Whether export runs for All datasets or the Current dataset. The comparison subset in the sidebar.
Practical rule

If comparison results look incomplete, check the sidebar selection first. If export results look incomplete, check the Export tab scope selector instead.
