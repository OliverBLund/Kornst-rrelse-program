Orientation

Workspace Tour

This page explains where to work in the app and what each selection changes.

Prefer an interactive Tutorial?

Open Help > Tutorials > Getting Started to spotlight each area in turn, or choose a workspace-specific Tutorial such as Individual Samples or Export. This page is the written reference.

Window Layout

The top of the window has two horizontal strips, one above the other:

  • Menu bar (top strip) — File, Analysis, View, and Help, plus the window title and window controls. Data loading, K methods, analysis settings, Tutorials, and Written Guides live here.
  • Toolbar (just below the menus) — Home, Individual Samples, Comparison, Reports, and Export on the left, with Log on the right. View shortcuts are Ctrl+0 through Ctrl+4; Tutorials and Written Guides are in the menu-bar Help hub.

Top-Level Tabs

Tab Use it for
Home Open files, tutorials, recent sources, and workspace status without clearing loaded samples.
Individual Samples Open dataset tabs, inspect one sample at a time, and recover files that need remapping.
Comparison Compare a selected subset of loaded datasets in shared Plot, Details, and Statistics views.
Reports Build a formatted HTML, PDF, or Word document from a report-type template (Individual, Cross-Sample Comparison, Full Project Summary, or K-Value Focus) that you can customize before generating.
Export Build the final export set for all datasets, the current dataset, or the selected dataset subset using the formats and content chosen inside the export workspace.

Dataset Tabs And Subtabs

  • Each loaded dataset gets its own tab inside Individual Samples.
  • Files that failed to load can appear as error tabs until they are fixed.
  • Inside a dataset tab you work across Plot, Results, and Statistics.

Samples Panel Behavior

  • The Samples panel remains visible on Home and in every workspace.
  • It provides Add, loaded sample cards, status filters, batch actions, and Scope & Groups. Global analysis settings remain in the Analysis menu.
  • The drop zone at the top of the Samples panel accepts dragged CSV, Excel, or TXT files; click it to choose processed or raw sieve import.
  • Clicking a card opens the matching dataset tab.
  • Expanding a card reveals quick actions such as inspect, log, properties, and remove.
  • The inclusion control is shared by Comparison, Reports, and the Export Selected scope. Batch selection for removal is a separate state.

What Selection Changes

Selection source Affects Does not affect
Included samples in Scope & Groups Comparison, report sample choices, and Export when its scope is Selected. The active sample and Export scopes All or Current.
No samples included Comparison may fall back to all loaded samples; Export Selected has no samples. Export All and Current.
Export scope selector Whether one export uses All, Current, or the shared Selected inclusion set. The inclusion set itself.
Practical rule

If comparison or Selected-scope output looks incomplete, check Scope & Groups. If Export has the wrong number of samples, also check whether its scope is All, Current, or Selected.
