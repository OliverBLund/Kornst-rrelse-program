Main Workflow

Results, Comparison & Export

After a dataset loads, your work moves through the four top-level tabs. Each tab now has its own guide — use the links below for the details.

The Four Tabs

Tab Use it for
Individual Samples One dataset at a time: the Plot, Results, and Statistics subtabs.
Comparison Two or more datasets together: comparison plots, details, and aggregate statistics.
Reports A formatted HTML, PDF, or Word document from a report-type template.
Export Data tables and plot image files for a chosen scope of datasets.

Calculate Or Recalculate

  • Loading a dataset normally calculates K-values immediately.
  • Changing temperature or porosity recalculates affected datasets automatically.
  • Use Analysis > Recalculate K Values (Ctrl+K) to rerun all open datasets explicitly.
Reports and Export share one Plot Style

Both tabs use the same Plot Style control: a preset sets typography and a palette sets colour. The rule is simple — the preset sizes the text, the palette colours the data. See the Reports and Export guides.
