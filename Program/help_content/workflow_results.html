Main Workflow

Results, Comparison & Export

After a dataset loads, most of your work happens in the per-dataset subtabs and the Comparison or Export top-level tabs.

Inspect One Dataset

Subtab What to check
Plot The grain-size distribution curve and plot controls for viewing or saving graphics.
Results The method table, status column, K-value units, and the detail panel for the selected method.
Statistics Percentiles, gradation parameters, classification, environmental values, and summary K-statistics.

Calculate Or Recalculate

  • Loading a dataset normally calculates K-values immediately.
  • Changing temperature or porosity settings recalculates affected datasets automatically.
  • Use Calculate K in the toolbar when you want to rerun all open datasets explicitly.

Use The Comparison Tab

  • You need at least 2 datasets to compare.
  • The comparison view contains Plot, Details, and Statistics.
  • The dataset subset comes from the sidebar selection or the comparison selection dialog.
  • If nothing is selected in the sidebar, comparison uses all loaded datasets.

Use The Export Tab

  1. Open the Export top-level tab.
  2. Choose the export scope: All, Current, or Selected datasets.
  3. Select the file formats and included content you want.
  4. Review the live preview, files-to-create tree, and destination folder.
  5. Run the export.
Selected scope

When the export scope is set to Selected, export follows the dataset subset managed through the sidebar selection state or comparison dataset management workflow.

Use the right export path

For formal output across multiple datasets, use the main Export tab. Do not rely on per-widget copy or placeholder export buttons when you need the final project deliverables.
