🚀 Getting Started

Welcome to the Grain Size Analysis application! This guide will help you get started with analyzing your grain size distribution data and calculating hydraulic conductivity values.

Quick Start Workflow

Follow these steps to analyze your first sample:

  1. Add Files - Click the "➕ Add Files" button in the sidebar
  2. Select Data - Choose one or more CSV/Excel files containing grain size distribution data
  3. Automatic Loading - Files are automatically loaded, validated, and K-values are calculated
  4. View Results - Explore the plots, results tables, and statistics for each dataset
  5. Export - Use the 💾 Export tab to save your results in multiple formats
💡 New in v0.9: Calculations happen automatically! When you load files or change parameters (temperature, porosity), K-values are recalculated automatically.

Understanding the Interface

Welcome Screen

When you first launch the application, you'll see a welcome screen with:

  • 📂 Recent Sessions - Quickly reload previously analyzed datasets

Main Tab Area

The main area has four top-level tabs:

  • 📊 Individual Samples - View each dataset with:
    • 🏠 Welcome tab - Returns to welcome screen

Your First Analysis

💡 Tip: Try loading sample data using the "📊 Load Sample Data" button on the welcome screen to familiarize yourself with the interface.

Step 1: Load Sample Data

  1. Click "➕ Add Files" in the control panel
  2. Select your CSV or Excel file(s) containing grain size data
  3. The application will automatically:
    • Detect the file format and column structure
    • Validate the data for common issues
    • Create a dataset tab for each file
    • Calculate K-values using all 14+ methods ✨
  4. Check the status column:
    • ✅ Auto-loaded - File loaded successfully, calculations complete
    • ⚠️ Needs Review - Requires manual column mapping
    • ❌ Failed - Contains validation errors
📌 Note: If files fail to auto-load, right-click on them and select "🗺️ Map Columns" to manually specify which columns contain particle sizes and percent passing values.

Step 2: Review Sample Data

  1. Click on a dataset tab to view its details
  2. The "Plot" sub-tab shows:
    • Grain size distribution curve
    • Interactive plot controls (zoom, pan, save)
  3. The "Results" sub-tab displays:
    • K values from all methods in multiple units (cm/s, m/s, m/d)
    • Formula used for each method
    • Color-coded status indicators (🟢 OK, 🟡 Warning, 🔴 Error)
  4. The "Stats" sub-tab shows:
    • Characteristic grain sizes (D10, D20, D30, D50, D60)
    • Uniformity coefficient (Cu) and Curvature coefficient (Cc)
    • Soil classification
    • Calculated porosity

Step 3: Adjust Parameters (Optional)

The "⚙️ Analysis Parameters" section in the sidebar is always visible. You can adjust:

  • 🌡️ Temperature - Set the water temperature (°C) for density and viscosity corrections
    • Affects both water density (ρ) and dynamic viscosity (μ) using Vuković & Soro (1992) formulas
    • Changes are applied automatically after 500ms (prevents excessive recalculation)
    • Default: 20°C
  • 🕳️ Porosity Mode - Choose between:
    • Simple Formula (Excel Compatible) - n = 0.255 × (1 + 0.83^U)
    • Urumovic Polynomial (Research) - Complex calculation based on grain size distribution
  • 🕳️ Manage Dataset Porosity - Set individual porosity values for each dataset
    • View calculated vs. current porosity
    • Update or reset porosity for specific datasets
    • Changes trigger automatic recalculation
⚡ Automatic Recalculation: When you change temperature, porosity mode, or dataset porosity, K-values are automatically recalculated for all affected datasets!

Step 4: Interpret Results

View results in the "Results" sub-tab with:

  • Color-coded status:
    • 🟢 Green (OK) - Method applicable, reliable result
    • 🟡 Yellow (Warning) - Result may be outside method's recommended range
    • 🔴 Red (Error) - Method not applicable for this sample
  • Multiple units - K values shown in cm/s, m/s, and m/d
  • Formula reference - See the actual equation used

Step 5: Export Results

Switch to the 💾 Export tab to save your results:

  1. Choose export scope: All datasets or Current dataset
  2. Select output directory using the Browse button
  3. Pick export formats from the cards on the left:
    • 📊 CSV Long - One row per K-value result
    • 📈 CSV Wide - One row per dataset, columns for each method
    • 📗 Excel - Multi-sheet workbooks
    • 📋 JSON - Structured data export
    • 🖼️ PNG - High-resolution plot images
    • 🎨 SVG - Vector graphics plots
    • 📄 PDF - Publication-ready plots
  4. Review the file tree preview showing what will be created
  5. Click 🚀 Export Now
