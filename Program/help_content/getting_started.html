🚀 Getting Started

Welcome to the Grain Size Analysis application! This guide will help you get started with analyzing your grain size distribution data and calculating hydraulic conductivity values.

Quick Start Workflow

Follow these steps to analyze your first sample:

  1. Add Files - Click the "➕ Add Files" button in the sidebar
  2. Select Data - Choose one or more CSV files containing grain size distribution data
  3. Review Status - Files will be automatically loaded and validated
  4. Calculate K Values - Click "🔬 Calculate All Samples" in the toolbar
  5. View Results - Explore the plots, results tables, and statistics

Understanding the Interface

Sidebar (Control Panel)

The left sidebar contains:

  • Sample Management - Add, remove, and view loaded files
  • File Status - Monitor loading progress (✅ Auto-loaded, ⚠️ Needs Review, ❌ Failed)
  • Batch Actions - Load all auto-detected files or review failed files
  • Analysis Parameters - Set temperature and porosity calculation mode (collapsible section)

Main Tab Area

The main area has three top-level tabs:

  • 📊 Individual Samples - View each dataset with plot, results, and statistics
  • 🔍 Comparison - Compare multiple datasets side-by-side
  • 📝 Reports - Generate professional reports

Toolbar

Quick access to common actions:

  • 🔬 Calculate All Samples - Run calculations on all loaded datasets
  • 📊 Export Results - Save results to CSV/Excel
  • 📈 Export Plot - Save current plot as image
  • 🔍 Compare Datasets - Switch to comparison view

Your First Analysis

💡 Tip: Try loading the included test_sample.csv file to familiarize yourself with the interface before analyzing your own data.

Step 1: Load Sample Data

  1. Click "➕ Add Files" in the control panel
  2. Select your CSV file(s) containing grain size data
  3. The application will automatically:
    • Detect the file format and column structure
    • Validate the data for common issues
    • Create a dataset tab for each file
  4. Check the status column:
    • ✅ Auto-loaded - File loaded successfully, ready for analysis
    • ⚠️ Needs Review - Requires manual column mapping
    • ❌ Failed - Contains validation errors
📌 Note: If files fail to auto-load, right-click on them and select "Map Columns" to manually specify which columns contain particle sizes and percent passing values.

Step 2: Review Sample Data

  1. Click on a dataset tab to view its details
  2. The "Plot" sub-tab shows the grain size distribution curve
  3. The "Stats" sub-tab displays:
    • Characteristic grain sizes (D10, D30, D50, D60)
    • Uniformity coefficient (Cu)
    • Soil classification
    • Calculated porosity

Step 3: Adjust Parameters (Optional)

Click to expand the "⚙️ Analysis Parameters" section in the sidebar:

  • Temperature - Set the water temperature (°C) for viscosity corrections
  • Porosity Mode - Choose between:
    • Simple Formula - Excel-compatible calculation: n = 0.255 × (1 + 0.83^U)
    • Urumovic Polynomial - Research-grade calculation based on grain size distribution

Step 4: Calculate K Values

  1. Click "🔬 Calculate All Samples" in the toolbar
  2. The application will calculate hydraulic conductivity using 14+ empirical methods
  3. Results appear in the "Results" sub-tab with:
    • K values in multiple units (cm/s, m/s, m/d)
    • Formula used for each method
    • Status indicators (OK, Warning, Error)

Step 5: Interpret Results

Switch to the "Results" tab to view:

  • Color-coded status:
    • Green (OK) - Method applicable, reliable result
    • Yellow (Warning) - Result may be outside method's recommended range
    • Red (Error) - Method not applicable for this sample
  • Statistical summary - Mean, median, min/max K values across all methods
