File Formats

The Grain Size Analysis application supports CSV and Excel files containing grain size distribution data. This guide explains the expected format and how to prepare your data.

Supported File Types

  • CSV files (.csv) - Comma-separated values
  • Excel files (.xlsx, .xls) - Microsoft Excel spreadsheets

Required Data Columns

Your file must contain at least two columns:

Column Description Units Example Values
Particle Size Sieve size or grain diameter millimeters (mm) 10.0, 5.0, 2.0, 1.0, 0.5
Percent Passing Cumulative percent finer than sieve percent (%) 100.0, 95.5, 85.2, 70.3, 45.8
️ Important: Data must represent percent passing (cumulative finer), not percent retained. If you have percent retained data, convert it using: % passing = 100 - % retained

File Format Requirements

Column Headers

The application can automatically detect columns with headers containing these keywords:

  • Particle Size: "size", "diameter", "sieve", "grain", "particle", "mm"
  • Percent Passing: "passing", "finer", "cumulative", "percent", "%", "curve"
Note: Headers are case-insensitive. "Grain Size (mm)" and "grain_size_mm" will both be recognized.

Data Requirements

  • Minimum data points: At least 3 sieve sizes
  • Grain size range: 0.001 mm to 1000 mm (typical range)
  • Percent passing range: 0% to 100%
  • Data order: Can be in any order (will be sorted automatically)
  • Numeric values: Must be valid numbers (no text in data cells)

Optional Metadata

You can include these optional parameters (if not provided, defaults will be used):

Parameter Default Value Valid Range
Temperature 20°C 0-50°C
Porosity Calculated from data 0.1-0.8

In this case, the application will identify "Sieve Size" and "Percent Passing" as the relevant columns.

Data Validation

When you load a file, the application automatically checks for:

  • Monotonicity: Percent passing should generally decrease with smaller grain sizes
  • Range validity: Values within acceptable limits
  • Duplicate entries: No duplicate grain sizes
  • Missing values: All required data present
Tip: If the application cannot auto-detect your file format, it will open the Column Mapper dialog, allowing you to manually specify which columns contain the required data.

Troubleshooting File Issues

File Shows "️ Needs Review"

Solution: Right-click the file and select "Map Columns" to manually specify data columns.

File Shows " Failed"

Possible causes:

  • Data represents "percent retained" instead of "percent passing"
  • Invalid numeric values (text in data cells)
  • Missing or incomplete data
  • File encoding issues

Solution: Right-click and select "Fix/Remap" to review and correct the data.

Data Appears Inverted

If your curve looks upside-down, your data is likely "percent retained" rather than "percent passing".

Solution: Convert your data using: % passing = 100 - % retained

Excel File Considerations

When using Excel files (.xlsx, .xls):

  • Data can be in any worksheet (first sheet is used by default)
  • Empty rows and columns are automatically skipped
  • Formatted cells are read as their underlying numeric values
  • Date/time cells may cause errors (ensure data cells contain numbers only)
