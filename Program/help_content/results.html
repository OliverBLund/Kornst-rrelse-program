Understanding Results

This guide helps you interpret the hydraulic conductivity calculation results and understand what the different values mean.

Results Tab Overview

After calculating K values, the Results tab displays a table with:

Column Description
Method Name of the empirical calculation method
K (cm/s) Hydraulic conductivity in centimeters per second
K (m/s) Hydraulic conductivity in meters per second (SI units)
K (m/d) Hydraulic conductivity in meters per day
Formula The specific formula variant used
Status OK, Warning, or Error indicator

Unit Conversions

K values are displayed in three common units:

1 cm/s = 0.01 m/s = 864 m/d

Which unit to use?

  • cm/s - Traditional geotechnical engineering
  • m/s - SI standard, scientific publications
  • m/d - Hydrogeology, groundwater modeling

Permeability Classification

K values can be classified by permeability:

K Range (m/s) Classification Typical Materials
> 10⁻² Very High Gravel, coarse sand
10⁻⁴ to 10⁻² High Clean sand, sand-gravel mixtures
10⁻⁵ to 10⁻⁴ Moderate Fine sand, silty sand
10⁻⁷ to 10⁻⁵ Low Silt, sandy silt
< 10⁻⁷ Very Low Clay, silty clay

Status Indicators

Green - OK

  • Method is applicable for this grain size distribution
  • All applicability conditions are met
  • Result is within the method's recommended range
  • Action: Result is reliable, use with confidence

Yellow - Warning ️

  • Result may be outside method's optimal range
  • Grain size distribution near applicability limits
  • Use with caution
  • Action: Check method applicability, consider corroborating with other methods

Red - Error

  • Method not applicable for this sample
  • Missing required grain size parameters (e.g., D₁₀, D₅₀)
  • Calculation failed or produced invalid result
  • Action: Do not use this result
Tip: Hover over a status indicator to see detailed information about why a method received that status.

Statistical Summary

The Stats tab provides statistical analysis of K values:

Measures of Central Tendency

  • Mean K - Average of all valid K values
  • Median K - Middle value (recommended for skewed distributions)

Measures of Spread

  • Standard Deviation - Variability among methods
  • Min/Max K - Range of calculated values
  • Variability - Ratio of Max/Min (how much methods disagree)
Interpretation: High variability (>10x difference between min and max) suggests:
  • Methods have different applicability for this sample
  • Some methods may be outside their valid range
  • Grain size distribution is unusual or complex

Recommended Best Estimate

To determine your best estimate of hydraulic conductivity:

  1. Filter by status - Consider only methods showing "OK" (green)
  2. Calculate median - Use the median of these OK methods
  3. Report range - Provide min-max as uncertainty bounds
  4. Note outliers - Identify methods significantly different from median
Kbest = median(KOK methods)
Uncertainty: [min(KOK methods), max(KOK methods)]

Common Result Patterns

All Methods Show Similar Values

Interpretation: High confidence in result

  • Grain size distribution is well-suited for empirical methods
  • Sample is uniform, well-graded sand
  • All methods agree on K value

Wide Spread of Values

Interpretation: Lower confidence, use caution

  • Sample may be outside typical range for some methods
  • Gap-graded or poorly sorted material
  • Consider which methods are most appropriate

Several Methods Show Errors

Possible causes:

  • Missing characteristic grain sizes (e.g., no D₁₀ for fine-grained soil)
  • Grain size distribution incomplete
  • Sample contains significant fines (clay/silt)

Action: Use only methods showing "OK" status

Quality Assurance Checks

️ Red Flags:
  • Outliers >100x different - Review input data for errors
  • All methods show errors - Check file format and data validity
  • Negative K values - Calculation error, report to developers
  • K > 1 m/s - Unusually high, verify data (unless gravel)
  • K < 10⁻⁹ m/s - Unusually low, empirical methods may not apply

Reporting Results

When reporting hydraulic conductivity, include:

  1. Best estimate - Median K from OK methods
  2. Uncertainty range - Min to max of OK methods
  3. Methods used - List which methods contributed to estimate
  4. Parameters - Temperature, porosity mode
  5. Grain size characteristics - D₁₀, D₅₀, D₆₀, Cu
  6. Soil classification - Based on grain size distribution

Example:

"Hydraulic conductivity estimated as K = 3.5×10⁻⁴ m/s (range: 2.8×10⁻⁴ to 4.2×10⁻⁴ m/s) based on median of 8 empirical methods (Hazen, Terzaghi, Beyer, Slichter, Kozeny-Carman, Shepherd, USBR, Sauerbrei) at T=20°C. Sample classified as fine to medium sand (D₁₀=0.15 mm, D₅₀=0.35 mm, Cu=2.3)."
