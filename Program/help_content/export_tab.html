Tab Guide

Export Tab

Use Export to create reusable CSV tables, a typed Excel workbook, and batches of standalone plot files. The workflow is Configure → Review → Export. For a formatted narrative document, use Reports instead.

Fast Workflow

  1. Choose All, Current, or Selected under Dataset Scope.
  2. Start with the recipe closest to your deliverable.
  3. Open Formats only when you need to add or remove a file type.
  4. Open Included Content only when the recipe needs finer adjustment.
  5. If plot files are selected, set their shared look in Plot Appearance.
  6. Open Review, choose the destination, and inspect Files to Create and the previews.
  7. Check the file count, then run the export.
Recipe first

A recipe configures both formats and content. If a recipe already matches the deliverable, leave Included Content collapsed. Any manual format or content change moves the recipe to Custom without discarding the change.

Configure: Dataset Scope

ScopeWhat is exported

CurrentOnly the sample chosen in the source selector.
SelectedThe included sample set managed through Scope & Groups in the always-visible Samples sidebar.
Selected uses the shared inclusion set

Export does not provide a second scope-management dialog. Use the sidebar Scope & Groups control to change included samples and group labels, then choose Selected here. Group labels are used by aggregate tables and group-aware comparison plots.

The Formats field is a grouped multi-select menu. Open it and tick any combination of data and plot formats.

Export PDF means a plot file

PDF in the Export tab creates standalone figure files. It does not create a multi-page report. Use Reports for a formatted HTML, PDF, or Word document.

Configure: Included Content

This section controls what is written inside the selected formats. Its three tabs are intentionally separate from styling:

TabControls
DataGrain distribution rows, selected percentiles, gradation values, classification, K results, formulas, validation messages, statistics, aggregates, units, and metadata.
IndividualOne plot per sample: grain-size curve, class histogram, K-value bar chart, and method-applicability heatmap.
ComparisonPlots across the export scope: distribution overlay, class-histogram comparison, K-value comparison, overall/group K boxplot, lognormal K distribution, and reliability matrix.

Some Comparison rows have a breakdown selector:

  • Per group organizes the plotted series by the group labels from Scope & Groups.
  • Per dataset uses dataset-level series.
  • Both creates both variants and therefore adds another file per selected plot format.
Plot selection is not plot styling

The Individual and Comparison checklists decide which figure files exist. They do not control fonts, colours, grids, or legend layout. Those choices belong to Plot Appearance.

Configure: Plot Appearance

Plot Appearance is shown only when PNG, SVG, or PDF is selected. Its settings apply to every selected individual and comparison plot:

  • Preset sets the overall typography and figure density.
  • Palette sets the data-series colours.
  • Customize… adjusts typography, curves, grids, and legend position, columns, opacity, and size.

Reports and Export share this saved style. A change in either workspace affects subsequently generated report and export plots.

Go to Sample is a navigation shortcut for an individual plot. It opens that plot's source sample in Individual Samples. It is unavailable for comparison plots because a collection plot has no single source sample.

Output Folder Structure

The exact names appear in Files to Create. A typical package looks like this:

chosen folder/
  tables/csv/
    combined_all_datasets_results_YYYYMMDD.csv
    wide_format_all_datasets_results_YYYYMMDD.csv
    grain_distribution_results_YYYYMMDD.csv
    aggregate_statistics_results_YYYYMMDD.csv
  workbooks/
    combined_all_datasets_results_YYYYMMDD.xlsx
  plots/
    BH-01/
      BH-01_results_YYYYMMDD_plot.png
    all_datasets/
      all_datasets_results_YYYYMMDD_distribution_overlay.png

Files are conditional: only the formats and content selected in Configure are created. With Selected scope, the collection plot folder is selected_datasets. Unsafe filename characters are replaced automatically.

Understand The File Count

Individual plots multiply by the number of samples and selected plot formats. For example, five samples × one individual plot type × PNG produces five plot files. Comparison plots are added once per chosen variant and format. CSV tables and the combined workbook are package-level files.

Samples and groups are written in natural name order, so BH-2 comes before BH-10. If duplicate sample labels occur, the writer assigns stable disambiguated labels.

Common Checks

Unexpected resultCheck
Too many or too few samplesCheck Dataset Scope. For Selected, edit the inclusion set in sidebar Scope & Groups.
No plot filesSelect at least one plot format and at least one plot type under Individual or Comparison.
Plot Appearance is missingSelect PNG, SVG, or PDF in Formats.
File count is larger than expectedCheck individual plot multiplication and Comparison rows set to Both.
Recipe shows CustomA format or content choice differs from the named recipe. The current choices remain active.
A plot needs investigationSelect it in Selected Plots; use Go to Sample when it belongs to one sample.

Run The Export

  1. Confirm the bottom summary: file count, dataset count, format count, destination, and estimated size.
  2. Select Export N Files.
  3. Large packages run in the background with cancellable progress.
  4. After completion, open representative CSV, Excel, and plot files from the destination.
