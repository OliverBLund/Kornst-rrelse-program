Tab Guide

Export Tab

The Export tab writes data tables and plot image files to a structured export folder. Choose a scope, the formats, and the content to include, then run the export.

Choose A Scope

Scope Exports
AllEvery loaded dataset.
CurrentThe dataset currently open in Individual Samples.
SelectedThe dataset subset chosen through the sidebar / comparison selection.
Scope is independent of the sidebar

Sidebar selection does not limit export unless the scope is set to Selected. If an export has more or fewer datasets than you expected, check the scope selector first.

Formats

  • Tables: CSV (long and wide layouts), Excel workbooks, and JSON.
  • Plots: PNG, SVG, and PDF image files.

Included Content

  • K-values, Statistics, and Metadata control which columns and sections appear in the tables.
  • Plots/Figures selects which plots are exported — per-dataset plots (grain-size curve, K-value bar, applicability heatmap) and collection plots (distribution comparison, K-value comparison, K box plots, the lognormal K distribution, and the reliability matrix).

Plot Style

The Export tab has the same Plot Style control as the Reports tab: a preset for typography and a palette for colour, plus Customize…. They share one setting, so report and export plots match. The rule is the same: the preset sizes the text, the palette colours the data.

Run The Export

  1. Review the live preview, the files-to-create tree, and the destination folder.
  2. Run the export. Large exports run in the background with a progress dialog you can cancel.
Use the right output path

For formal deliverables across multiple datasets, use this tab rather than per-widget copy buttons. For a formatted document (HTML/PDF/Word), use the Reports tab instead.
