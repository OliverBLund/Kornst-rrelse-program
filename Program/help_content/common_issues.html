Troubleshooting

Common Issues

Use this page for short checks. For full mapping or recovery steps, open the dedicated mapping page.

Curve Or Data Looks Wrong

Problem Check first
Curve looks inverted The mapped column may be percent retained instead of percent passing.
No D10, D50, or D60 The imported sieve range may not bracket the percentile needed for interpolation.
Many methods show warnings or errors Review the percentiles, gradation values, and method status in the dataset Results tab.

Comparison Is Empty Or Incomplete

  • You need at least 2 datasets.
  • Check the sidebar selection state. Comparison uses the selected subset.
  • If needed, clear the selection so comparison falls back to all loaded datasets.

Export Does Not Match What You Expected

  • The Export tab uses its own scope selector: All, Current, or Selected.
  • Selected uses the included sample set from sidebar Scope & Groups.
  • If a named recipe is close but not exact, adjust Formats or Included Content; the recipe changes to Custom.
  • If plot files are missing, select both a plot format and at least one Individual or Comparison plot type.
  • Use Review > Files to Create as the final check of dated filenames, folders, and file count.
  • If K-values are missing, rerun calculations before exporting.

Report Or Export Plots Look Wrong

Problem Check first
Plot colours are not what you picked Colour comes from the palette, not the preset. Set Palette under Reports Plot Style or Export Plot Appearance; Categorical keeps the standard colours.
Fonts too small or too large Typography comes from the preset. Use Presentation for larger text, or open Customize… to adjust title, axis, tick, and legend sizes.
Report and export plots do not match They share one saved appearance. Confirm the preset, palette, and Customize overrides, then regenerate or re-export.
Per-sample plots are missing from a report Per-sample grain curves and K-value bars are opt-in. Enable them under Plots to Include before generating.
A large report is slow Generation runs in the background with a progress dialog; you can let it finish or press Cancel. Turning off per-sample plots reduces the number of figures.

Excel Imported The Wrong Sheet Or Layout

  • Reopen the mapper from the error tab or reimport the workbook.
  • Check the selected sheet, header row, and column choices.
  • Use range selection only for irregular single-sheet mapping.
