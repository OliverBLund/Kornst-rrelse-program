Global Controls

Analysis Parameters

The Analysis menu separates workspace-wide choices from dataset inputs. Use Analysis Settings… for shared methods and classification, and Dataset Inputs… for temperature and effective porosity.

The Analysis Menu

The Analysis menu in the menu bar opens a list of global actions:

Menu item What it does
Analysis Settings… Sets the workspace temperature default and automatic porosity formula, and opens the shared classification and K-method selectors.
Dataset Inputs… Edits temperature and effective porosity for one, several selected, or all loaded datasets. It also restores exact automatic porosity values.
Recalculate K Values Ctrl+K Reruns the K-value calculation for every open dataset using each dataset's current inputs and the active methods.
Update Comparison Switches to the Comparison tab and refreshes it from the current datasets (needs at least two datasets).
One source of truth

The classification scheme, automatic porosity formula, and active K-method set are workspace-wide. Temperature and effective porosity are stored per dataset; the workspace temperature acts as the default and can be applied to every loaded dataset.

Temperature

  • Set in degrees Celsius (range 0–50 °C, default 20 °C).
  • Temperature affects water density and viscosity in the hydraulic-conductivity calculations (Vukovic & Soro, 1992).
  • Changing temperature recalculates affected datasets automatically after a short delay.
  • Use one value that matches the water or test conditions you want to represent.

Calculated Porosity

When a dataset has no manual porosity, the app estimates it. The Calculated Porosity mode controls how:

Mode How it estimates porosity
Simple Formula (Excel Compatible) n = 0.255 × (1 + 0.83U), where U is the uniformity coefficient. Matches the spreadsheet workflow.
Urumovic Polynomial (Research) A research polynomial based on the grain-size distribution.
  • The mode only applies to datasets that are not manually overridden.
  • Use Dataset Inputs… to set a manual porosity for one or more datasets.
  • The selected mode affects any method that depends on porosity; affected datasets recalculate after the change.

Where porosity appears, and how to override it

  • Each dataset's automatic porosity (symbol n) is derived from the uniformity coefficient Cu — it is not Cu itself. It appears in the Auto porosity column and in the dataset's Statistics subtab.
  • Dataset Inputs… shows the automatic estimate, the effective value currently used, and its source. Use automatic restores the exact calculated value. Applying any change recalculates K and refreshes comparison, report, and export data.
Check the dataset view

After changing global parameters, reopen the dataset Results or Statistics subtabs to confirm that the updated values still look reasonable for the sample.

Operational Advice

  • Use one consistent temperature across datasets that belong to the same comparison.
  • Recheck warnings after changing the porosity mode, because some methods may move in or out of their recommended range.
  • Input and method changes refresh the comparison automatically; Update Comparison remains available as a manual refresh.
  • Use the Active K methods selector in Analysis Settings to keep the method set consistent across the datasets you intend to compare or report.
