Global Controls

Analysis Parameters

The sidebar contains global controls that affect loaded datasets. These settings are meant for operational use, so keep them consistent with the test conditions you want to report.

Temperature

  • Temperature is applied to loaded datasets and used in the hydraulic conductivity calculations.
  • Changing temperature triggers recalculation after a short delay.
  • Use values that match the water or test conditions you want to represent.

Porosity Mode

  • The app can calculate porosity automatically using the available mode options in the sidebar.
  • The selected mode affects any method that depends on porosity.
  • After the mode changes, affected datasets are recalculated.
Check the dataset view

After changing global parameters, reopen the dataset Results or Statistics subtabs to confirm that the updated values still look reasonable for the sample.

Operational Advice

  • Use one consistent temperature setting across datasets that belong to the same comparison.
  • Recheck warnings after changing porosity mode because some methods may move in or out of their recommended range.
  • If you are comparing several datasets, avoid changing global settings midway through review without rerunning the comparison.
