Global Controls

Analysis Parameters

Global settings affect hydraulic-conductivity calculations and classification across loaded datasets. You can reach them two ways: the quick controls in the sidebar, and the Analysis menu in the top toolbar. Keep them consistent with the test conditions you want to report.

The Analysis Menu

The Analysis button in the top toolbar opens a menu of global actions:

Menu item What it does
Analysis Settings… Opens a dialog with the global temperature, the calculated porosity mode, and the current classification scheme, plus buttons to open the porosity and scheme dialogs. These are the same values as the sidebar controls.
Dataset Porosity… Opens the porosity manager for setting a manual porosity per dataset, overriding the automatic calculated value.
Classification Scheme… Chooses the soil classification scheme used for grain-size class labels and zones.
Recalculate K Values Ctrl+K Reruns the K-value calculation for every open dataset using the current temperature and active methods.
Choose K Methods… Selects which empirical K-methods are active. The choice is applied across all result surfaces (tables, plots, reports, and exports).
Update Comparison Switches to the Comparison tab and refreshes it from the current datasets (needs at least two datasets).
One source of truth

The temperature and porosity mode in the Analysis Settings dialog and the sidebar are the same setting — changing one updates the other, so reports, exports, plots, and tables all share the same parameters.

Temperature

  • Set in degrees Celsius (range 0–50 °C, default 20 °C).
  • Temperature affects water density and viscosity in the hydraulic-conductivity calculations (Vukovic & Soro, 1992).
  • Changing temperature recalculates affected datasets automatically after a short delay.
  • Use one value that matches the water or test conditions you want to represent.

Calculated Porosity

When a dataset has no manual porosity, the app estimates it. The Calculated Porosity mode controls how:

Mode How it estimates porosity
Simple Formula (Excel Compatible) n = 0.255 × (1 + 0.83U), where U is the uniformity coefficient. Matches the spreadsheet workflow.
Urumovic Polynomial (Research) A research polynomial based on the grain-size distribution.
  • The mode only applies to datasets that are not manually overridden.
  • Use Dataset Porosity… (Analysis menu or sidebar) to set a manual porosity for specific datasets.
  • The selected mode affects any method that depends on porosity; affected datasets recalculate after the change.
Check the dataset view

After changing global parameters, reopen the dataset Results or Statistics subtabs to confirm that the updated values still look reasonable for the sample.

Operational Advice

  • Use one consistent temperature across datasets that belong to the same comparison.
  • Recheck warnings after changing the porosity mode, because some methods may move in or out of their recommended range.
  • If you change global settings midway through a review, rerun Update Comparison so the comparison and its plots reflect the new values.
  • Use Choose K Methods… to keep the method set consistent across the datasets you intend to compare or report.
