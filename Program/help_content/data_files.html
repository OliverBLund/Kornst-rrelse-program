Data Input

Data Format & Files

The program accepts CSV and Excel workbooks that contain grain-size data in millimeters. It can import either pre-calculated percent-passing data or raw sieve weighings.

Four ways to load

Use the welcome-screen buttons; the File menu (Open Processed Sieve Data… / Open Raw Sieve Weighings…); the sidebar + Add button; or drag CSV, Excel, or TXT files onto the drop zone at the top of the sidebar. Click the drop zone to choose processed or raw sieve import.

Supported File Types

Type Extensions Notes
CSV .csv Best for simple two-column or clean multi-column tables.
Excel workbook .xlsx, .xls Useful when data is split across sheets or needs manual mapping.

Accepted Input Styles

Style Required columns Used when
Calculated data Particle size in mm and cumulative percent passing Your spreadsheet already contains the sieve curve values you want to analyse.
Raw sieve weighings Sieve size, empty sieve weight, and sieve plus sample weight You want the app to calculate cumulative percent passing from measured sieve weights.
Important

The main analysis expects percent passing, not percent retained. If your file contains retained values, convert them before analysis or remap the correct column.

Expected Values

  • Particle sizes must be numeric and positive.
  • Units should be millimeters.
  • Percent passing should stay between 0 and 100.
  • You need at least 3 valid rows to create a dataset.
  • The app sorts particle sizes automatically, so the source rows do not need to be pre-sorted.

Column Names The App Can Recognize

Target Common header words
Particle size size, sieve, diameter, grain, particle, mm
Percent passing passing, finer, cumulative, percent, %
Raw sieve weights empty, sieve, sample, weight, mass

When To Use The Mapper

Open the mapper when the correct columns are present but the loader cannot safely detect them. This is common for Excel workbooks, irregular lab sheets, and files that include several unrelated columns.
