Data Input Guide

Data Format & Files

Start with one of the four layouts below. Particle size must be in millimeters (mm). Use processed data when percent passing is already calculated, or raw data when you have sieve weights.

Why a gibberish header may still load

Detection does not depend on one exact header cell. Another header row, the remaining column roles, and the numeric pattern may still provide enough evidence. Changing an unrelated result column also has no effect on the detected raw columns. The mapper opens when the sheet no longer provides enough evidence for any plausible processed or raw candidate.

Percent passing is not percent retained

Processed analysis expects cumulative percent passing: the percentage of the sample finer than each particle size. Retained columns are not converted automatically because cumulative retained and per-sieve retained require different calculations. Convert cumulative retained in the source with passing = 100 - retained, or import the original sieve weights as Raw Sieve Weighings.

Review before importing

The mapper proposes candidates in a checked list. Selecting one candidate highlights its source cells and previews that interpreted curve. Clear any candidate that should not be imported, then verify:

  • the proposed sample name and source columns;
  • particle-size units are millimeters;
  • the percentage column is cumulative percent passing or finer, not retained or incremental;
  • the preview follows a plausible direction and remains within 0 to 100.

Only checked candidates are created when you choose Import N samples.

Experimental, not a universal workbook importer

Retained values, incremental percentages such as % Volume In, merged or irregular headers, mixed particle-size units, and transposed tables may not produce safe candidates. Cancel the candidate review and use the ordinary mapper, or prepare each sample as a supported single-sample table. Do not import a candidate when its source columns or preview are unclear.

Delimited Text and Excel Rules

FormatSupported filesReliable structure
CSV.csvPlain tabular data using a detected comma, semicolon, tab, or pipe delimiter. The comma-separated examples above use this same reader.
Delimited TXT.txtThe same supported table structure as CSV, commonly written by laboratory instruments with tab or semicolon separators. Free-form text and reports are not supported.
Excel.xlsx, .xlsUse one clearly named worksheet per sample when possible. Clean and recognizable irregular sheets may load automatically; uncertain sheets open the mapper.

Ordinary imports treat one delimited table or worksheet as one dataset. To review several candidates from one supported table, use Add > Multiple Samples in One File (Experimental); otherwise map one sample at a time.

Validation Checklist

  • Particle sizes are numeric, positive, and expressed in mm.
  • Processed values are cumulative percent passing between 0 and 100.
  • Raw weights are numeric and expressed in g.
  • Every dataset contains at least 3 valid rows.
  • Headers identify the values and units; title or note rows are excluded by selecting the correct header row in the mapper.
  • The mapper preview shows a plausible curve before the dataset is accepted.

When the Mapper Opens

The mapper is a confirmation step, not a failure. It opens when the program cannot find a plausible processed curve or raw-sieve table. This can happen when key header clues are missing, too few valid rows are present, or the required columns cannot be related safely. Confirm the worksheet and header row first, then assign the required column roles and inspect the preview before continuing.
