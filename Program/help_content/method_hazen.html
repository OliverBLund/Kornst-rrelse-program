Hazen Method

The Hazen method is one of the most widely used empirical formulas for estimating hydraulic conductivity from grain size distribution. Developed by Allen Hazen in the late 19th century, it remains popular due to its simplicity and reasonable accuracy for uniform sands.

Formula

K = C × f(n) × D₁₀² × (ρg/μ)

Where:

  • K = Hydraulic conductivity (cm/s)
  • C = Coefficient = 6 × 10⁻⁴ cm⁻¹
  • D₁₀ = Effective grain size (cm)
  • f(n) = Porosity function = (n - 0.13) / (1 - n)^(1/3)
  • n = Porosity (dimensionless)
  • ρg/μ = Temperature correction factor

Porosity Function

The application uses a porosity-dependent form of the Hazen formula:

f(n) = (n - 0.13) / (1 - n)^(1/3)

This accounts for the effect of void space on hydraulic conductivity.

Required Parameters

Parameter Symbol How Obtained
Effective grain size D₁₀ Interpolated from grain size distribution (10% passing)
Porosity n Calculated from uniformity coefficient or measured
Temperature T User-specified (default 20°C)

Applicability Ranges

Parameter Recommended Range Notes
Grain size (D₁₀) 0.1 - 3.0 mm Fine to coarse sand
Uniformity coefficient Cu < 5 Uniform to moderately graded sands
Porosity 0.25 - 0.50 Typical for sands
Fine content < 5% Clean sands
Warning: The Hazen method is not appropriate for:
  • Clayey or silty soils
  • Poorly graded or gap-graded materials
  • Gravels or very coarse materials
  • Soils with significant fines content (>5%)

Temperature Correction

The method includes automatic temperature correction using the Vuković & Soro (1992) polynomial:

K(T) = K₂₀ × [ρ(T)g/μ(T)] / [ρ(20°C)g/μ(20°C)]

This adjusts for changes in water viscosity with temperature.

Example Calculation

Given Data

D₁₀ = 0.15 mm = 0.015 cm
D₆₀ = 0.35 mm = 0.035 cm
Cu = D₆₀/D₁₀ = 2.33
Porosity (n) = 0.40
Temperature = 20°C

Step 1: Calculate Porosity Function

f(n) = (n - 0.13) / (1 - n)^(1/3)
f(0.40) = (0.40 - 0.13) / (1 - 0.40)^(1/3)
f(0.40) = 0.27 / 0.843
f(0.40) = 0.320

Step 2: Temperature Correction (at 20°C)

ρg/μ at 20°C = 9.76 × 10⁷ cm⁻¹s⁻¹
(Reference value from tables)

Step 3: Calculate K

K = 6×10⁻⁴ × 0.320 × (0.015)² × 9.76×10⁷
K = 6×10⁻⁴ × 0.320 × 2.25×10⁻⁴ × 9.76×10⁷
K = 4.22×10⁻³ cm/s
K = 4.22×10⁻⁵ m/s
K = 3.65 m/d

Comparison with Simplified Hazen

The classic simplified Hazen formula (without porosity function):

K = C × D₁₀²

Where C typically ranges from 100-150 (using D₁₀ in cm, K in cm/s).

Advantages

  • Simple and well-established
  • Only requires D₁₀
  • Widely validated for uniform sands
  • Includes temperature correction
  • Accounts for porosity effects

Limitations

  • Limited to uniform, clean sands
  • Less accurate for well-graded materials
  • Not suitable for gravels or fine-grained soils
  • Requires accurate D₁₀ measurement

Historical Background

Allen Hazen (1869-1930) was an American civil engineer who developed this formula based on extensive filter sand experiments at the Massachusetts State Board of Health. His original work focused on water filtration, but the formula has since been widely adopted for hydraulic conductivity estimation.

Original Reference

Hazen, A. (1892). "Physical properties of sands and gravels with reference to use in filtration." Massachusetts State Board of Health, 24th Annual Report, pp. 539-556.

Practical Tips

Best Practices:
  • Ensure grain size distribution extends below 10% passing
  • Check that Cu < 5 for optimal accuracy
  • Compare with other methods (Terzaghi, Beyer) for validation
  • Use laboratory-measured porosity if available
  • Apply only to clean, granular materials
