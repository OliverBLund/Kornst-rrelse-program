⚙️ Parameters Guide

Understanding and properly setting analysis parameters is crucial for accurate hydraulic conductivity calculations. This guide explains each parameter and how it affects results.

Global Parameters

Parameters set in the Control Panel apply to all loaded samples. Access these by expanding the "⚙️ Analysis Parameters" section in the sidebar.

Temperature

What It Is

Water temperature (°C) at which hydraulic conductivity is being measured or estimated.

Why It Matters

Temperature affects water viscosity, which directly impacts flow through porous media. Most empirical formulas include temperature corrections to normalize K values to standard conditions.

How It's Used

The application uses the Vuković & Soro (1992) polynomial method to calculate the temperature correction factor:

ρ/μ(T) = polynomial function of temperature

This factor is applied to most calculation methods to adjust K values for the specified temperature.

Typical Values

Setting Temperature Use Case
Laboratory (standard) 20°C Most laboratory tests
Cold groundwater 10°C Deep aquifers, winter conditions
Warm groundwater 15-25°C Shallow aquifers, temperate climate
Field conditions Variable Match actual field temperature
📌 Default: 20°C (standard laboratory temperature)
Valid range: 0-50°C
⚠️ Warning: Temperatures outside 0-50°C may produce unreliable viscosity corrections and should be avoided unless you have specific data for extreme conditions.

Porosity Calculation Mode

What It Is

The method used to calculate soil porosity (n) from grain size distribution data. Porosity represents the void space between soil particles.

Two Calculation Methods

1. Simple Formula (Excel Compatible)

Formula:

n = 0.255 × (1 + 0.83U)

Where U = Uniformity Coefficient = D₆₀ / D₁₀

Advantages:

  • ✅ Fast and simple calculation
  • ✅ Matches Excel VBA implementation exactly
  • ✅ Based on uniformity coefficient only
  • ✅ Suitable for most practical applications

Limitations:

  • ❌ Less accurate for poorly graded soils
  • ❌ Doesn't account for full grain size distribution

2. Urumovic Polynomial (Research)

Formula: Complex polynomial based on the entire grain size distribution curve

Advantages:

  • ✅ More accurate for complex grain size distributions
  • ✅ Accounts for full sieve analysis data
  • ✅ Research-grade calculation
  • ✅ Better for poorly graded or gap-graded soils

Limitations:

  • ❌ More computationally intensive
  • ❌ Requires complete grain size distribution
  • ❌ May differ from simple Excel calculations

Which Method Should You Use?

Use Simple Formula When... Use Urumovic When...
• Matching Excel results
• Quick estimations
• Well-graded sands
• Standard applications		 • Research applications
• Complex distributions
• Gap-graded soils
• Maximum accuracy needed
💡 Recommendation: Start with the Simple Formula for compatibility with existing workflows. Switch to Urumovic if you need higher accuracy or are working with unusual grain size distributions.

Sample-Specific Parameters

Some parameters can be adjusted for individual samples in the "Stats" tab of each dataset:

Manual Porosity Override

You can override the calculated porosity value if you have measured porosity data from laboratory tests.

How to set:

  1. Open the "Stats" tab for a dataset
  2. Find the "Porosity Settings" section
  3. Enter your measured porosity value (0.01-0.99)
  4. Click "Update"
📌 Note: Manual porosity overrides are saved per-sample and will be used in all K-value calculations for that sample.

Typical Porosity Values

Soil Type Typical Porosity (n)
Uniform coarse sand 0.39 - 0.41
Well-graded sand 0.30 - 0.35
Fine sand 0.40 - 0.50
Silt 0.45 - 0.55
Clay 0.45 - 0.70
Gravel 0.25 - 0.35

Sample Mass Assumption

📌 Technical Note: The application assumes a 100g sample mass for internal calculations. This value cancels out mathematically in the formulas, so the actual mass of your sample does not affect the results. Your data should represent percentages (cumulative percent passing), not absolute masses.

Impact on Calculations

Methods Sensitive to Temperature

Most methods (Hazen, Terzaghi, Beyer, Slichter, etc.) include temperature correction factors.

Methods Sensitive to Porosity

Methods that explicitly use porosity in their formulas:

  • Hazen (uses porosity function)
  • Kozeny-Carman (porosity-dependent)
  • Zamarin (uses porosity ratio)
  • Barr (cubic ratio porosity function)

Methods Using Special Grain Size Parameters

Some methods calculate specialized grain size parameters from the full distribution:

  • Harmonic mean diameter (Kozeny-Carman)
  • Geometric mean (Krumbein-Monk, Zamarin)
  • Special diameter calculations (Zunker, Kruger)

Best Practices

  1. Set temperature first - Match your field or laboratory conditions
  2. Choose porosity method - Simple for routine work, Urumovic for research
  3. Review calculated porosity - Check if values are reasonable for your soil type
  4. Document your choices - Record parameter settings for reproducibility
  5. Sensitivity analysis - Try both porosity methods to see if results differ significantly
💡 Pro Tip: For quality assurance, calculate K values with both porosity methods and compare results. If they differ significantly, investigate which method is more appropriate for your soil type.
