Getting Started

Use this page to get a first dataset into the workspace and understand what the application does next.

Good first step

From the welcome screen, use Processed Sieve Data when your file already contains sieve size and percent passing, Raw Sieve Weighings when the app should calculate percent passing from sieve weights, or Open Demo Sample to load the built-in demo dataset set.

Try an interactive Tutorial

Open Help > Tutorials for step-by-step highlights inside the real workspace:

  • Getting Started — Home, navigation, the Samples panel, settings, log, and status line.
  • Individual Samples — the active sample's Plot, Results, and Statistics subtabs.
  • Comparison — comparison plots, details, and statistics across the included samples.
  • Reports — report type, scope, sections, plots, output format, preview, and saving.
  • Export — scope, recipes, formats, included content, plot appearance, Review, and final export.

Open Help > Written Guides…, or press F1, for the reference companion to those Tutorials.

First Run

  1. Load files any of four ways: the welcome-screen buttons; the File menu (Open Processed Sieve Data… / Open Raw Sieve Weighings…); the Samples panel + Add button (above the loaded sample cards); or by dragging CSV, Excel, or TXT files onto the drop zone at the top of the Samples panel (click the drop zone to pick processed or raw sieve import).
  2. If the file layout is simple, the dataset loads directly.
  3. If the workbook has multiple sheets or ambiguous columns, the app opens the sheet selector or column mapper.
  4. When at least one dataset loads, Individual Samples opens automatically. Home remains available and the Samples panel stays visible.

Fast Workflow

  1. Load: bring CSV or Excel data into the workspace.
  2. Check status: confirm whether each item loaded cleanly or needs review.
  3. Inspect: open the dataset tab and review the Plot, Results, and Statistics subtabs.
  4. Calculate: results are usually calculated automatically; use Analysis ▸ Recalculate K Values (Ctrl+K) if you want to rerun all open datasets.
  5. Compare and export: move to the Comparison, Reports, or Export top-level tabs when you are ready to work across datasets.

What You Should See

Area What to expect
Menu bar (top strip) The classic menus File, Analysis, View, and Help, with the window title and the minimise / maximise / close buttons on the right. Loading, exports, K methods, and the analysis settings live here.
Toolbar (below the menus) The five workspace tabs — Home, Individual Samples, Comparison, Reports, and Export — on the left, with Log on the right. Use the menu-bar Help hub for Tutorials and Written Guides.
Samples panel The always-visible Samples workspace: Add, loaded sample cards, status filters, batch selection, and Scope & Groups. Global analysis settings remain in the Analysis menu.
Dataset tabs Each successfully loaded dataset gets its own tab. Files that need manual correction can open as error tabs instead.
Per-dataset view Each dataset tab contains Plot, Results, and Statistics.
Automatic calculation

Loading a dataset usually triggers K-value calculation immediately. Changing temperature or porosity settings recalculates affected datasets again, so there is often no separate manual calculation step after import.

Export now has its own workspace

The Export tab uses a Configure → Review workflow: choose scope, start from a recipe, adjust formats/content if needed, inspect the actual files and plots, then export the package.

Every tab has its own guide

The Tabs & Subtabs section in the navigation has a dedicated page for each top-level tab, covering its subtabs and controls: Individual Samples, Comparison, Reports, and Export. Global settings are covered under Use The App in Analysis Parameters.

Reports, exports, and plot styling

Reports and Export share the same saved plot appearance: the preset sets typography and density, the palette sets data colours, and Customize stores detailed overrides.
