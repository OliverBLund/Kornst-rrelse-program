Getting Started

Use this page to get a first dataset into the workspace and understand what the application does next.

Good first step

From the welcome screen, use Processed Sieve Data when your file already contains sieve size and percent passing, Raw Sieve Weighings when the app should calculate percent passing from sieve weights, or Open Demo Sample to load the built-in demo dataset set.

Take the guided tour

For an interactive walkthrough that highlights each part of the window, open the top Help menu:

  • Help > Startup Guide — a tour of the whole workspace (sidebar, Analysis menu, the four tabs, log, and status line).
  • Help > Guide Individual Samples — a focused walkthrough of the active dataset's Plot, Results, and Statistics subtabs.
  • Help > Guide Reports — a detailed walkthrough of report type, sample scope, sections, plots, output formats, preview, and save/export behavior.
  • Help > Guide Export — a detailed walkthrough of dataset scope, CSV/Excel/plot formats, included content, file preview, plot queue, and final export.

These written pages (Help > Help Topics, or F1) are the reference companion to those tours.

First Run

  1. Open files from the welcome screen or from Add Files in the top toolbar.
  2. If the file layout is simple, the dataset loads directly.
  3. If the workbook has multiple sheets or ambiguous columns, the app opens the sheet selector or column mapper.
  4. When at least one dataset loads, the welcome screen is replaced by the main workspace and the left sidebar becomes visible.

Fast Workflow

  1. Load: bring CSV or Excel data into the workspace.
  2. Check status: confirm whether each item loaded cleanly or needs review.
  3. Inspect: open the dataset tab and review the Plot, Results, and Statistics subtabs.
  4. Calculate: results are usually calculated automatically; use Calculate K if you want to rerun all open datasets.
  5. Compare and export: move to the Comparison, Reports, or Export top-level tabs when you are ready to work across datasets.

What You Should See

Area What to expect
Top toolbar Individual Samples, Comparison, Reports, Export, plus Add Files, Calculate K, and Help.
Sidebar Loaded file cards, status indicators, dataset selection controls, and global analysis controls. It is hidden on the welcome screen and shown once datasets are loaded.
Dataset tabs Each successfully loaded dataset gets its own tab. Files that need manual correction can open as error tabs instead.
Per-dataset view Each dataset tab contains Plot, Results, and Statistics.
Automatic calculation

Loading a dataset usually triggers K-value calculation immediately. Changing temperature or porosity settings recalculates affected datasets again, so there is often no separate manual calculation step after import.

Export now has its own workspace

The Export tab now lets you choose All, Current, or Selected datasets, preview files before they are created, and export grouped outputs such as tables, workbooks, and per-dataset plots.

Every tab has its own guide

The Tabs & Subtabs section in the navigation has a dedicated page for each top-level tab, covering its subtabs and controls: Individual Samples, Comparison, Reports, and Export. Global settings are covered under Use The App in Analysis Parameters.

Reports, exports, and plot styling

The Reports and Export tabs share one Plot Style control: a preset sets the typography and a palette sets the colours — the preset sizes the text, the palette colours the data.
