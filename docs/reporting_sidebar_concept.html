Key UI moves

This concept trims the sidebar by demoting secondary inputs and giving sample selection the visual dominance it already deserves.

1. Scope upfront

Type, subtype, and template stay visible at the top so the user always knows what kind of report they are composing.

2. Sample workspace

Many-sample handling moves from a long checkbox stack to a searchable tray with compact rows, filter chips, and status tags.

3. Progressive disclosure

Sections, appendix settings, branding, and notes stop competing at the same visual level.

4. Action certainty

The footer stays pinned and always states the current scope, so generating feels deliberate instead of buried.
