# Documentation Prompt

Use this in the later dedicated documentation session.

## Task

Audit and update the in-app help/documentation system for the Grain Size Analysis program.

## Goal

Bring the help system up to date for the next beta stage, with a strong focus on onboarding, practical usage, and consistency with the current UI.

## Scope

1. Audit all existing help pages for accuracy against the current application.
2. Prioritize the pages required for a new user to successfully start using the program.
3. Remove emoji-based styling/copy and replace that visual language with a cleaner icon strategy aligned with `qtawesome` / Font Awesome usage in the app.
4. Lightly refresh the help-page styling so it better matches the newer shell / welcome / dialog design direction.
5. Keep the writing practical, short, and operational rather than verbose or marketing-heavy.

## Highest-Priority Content To Cover

- Getting started
- Supported file formats
- Expected data format / column structure
- Excel multi-sheet behavior
- Column mapping / remapping workflow
- Error recovery workflow
- Basic workflow:
  - load data
  - inspect plots/results/statistics
  - calculate
  - compare
  - export
- Surface-level navigation/orientation:
  - top-level tabs
  - dataset tabs
  - per-dataset subtabs
  - sidebar behavior
  - what selection affects in comparison/export

## Important Constraints

- Do not overload pages with long explanations.
- Focus on what the user needs to do, where to do it, and what to expect.
- Preserve technical correctness.
- Avoid duplicate explanations across pages.
- Prefer short sections, clean hierarchy, and direct language.

## Expected Deliverables

1. Documentation audit summary
2. Proposed page structure / information architecture
3. Updated or newly created help pages
4. Styling cleanup pass
5. Final consistency review against the live app UI
