Description:
''Grain Size Analysis'' has been built entirely using Python (version 3.11, using the PyQt6 and PyQt6-WebEngine libraries for the user interface, reporting preview, and PDF export). The coding has been performed by Oliver B. Lund, DTU Sustain. The program supports grain-size data import, column mapping, grain-size distribution analysis, empirical hydraulic-conductivity estimation, comparison plots, reporting, and export. The development has been carried out in collaboration with Poul L. Bjerg, DTU Sustain, with layout and workflow decisions informed by project-specific testing and feedback.
